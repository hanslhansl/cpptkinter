# cpptkinter
Have you ever thought to yourself 'tkinter is a great Python library, it's a shame nothing comparable exists in c++'? No? Well, here you go anyways.

## terminology
- Tcl: the [scripting language](https://en.wikipedia.org/wiki/Tcl)
- Tk: the [gui toolkit](https://en.wikipedia.org/wiki/Tk_(software)) available in tcl.
- Tkinter: the [Python binding](https://en.wikipedia.org/wiki/Tkinter) for tk.
- Cpptkinter: [this project](https://github.com/hanslhansl/cpptkinter)

This terminology applies to the documentation and source annotations.
