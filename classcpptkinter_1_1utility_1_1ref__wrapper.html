Detailed Description

template<typename T>
requires std::same_as<T, std::remove_cvref_t<T>>
class cpptkinter::utility::ref_wrapper< T >

Like std::reference_wrapper but can be constructed from rvalues (temporaries).

Use with caution, as this can easily lead to dangling references.
