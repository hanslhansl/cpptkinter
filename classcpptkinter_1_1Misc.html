◆ bbox()

std::array< long long, 4 > cpptkinter::Misc::bbox ( const cnfs::grid_bbox &  cnf = {})
inline

Return a tuple of integer coordinates for the bounding box of this widget controlled by the geometry manager grid.

If COLUMN, ROW is given the bounding box applies from the cell with row and column 0 to the specified cell. If COL2 and ROW2 are given the bounding box starts at that cell. The returned integers specify the offset of the upper left corner in the master widget and the width and height.
